# Crypto Test Task

Адаптивная web-страница с актуальными ценами криптовалют, фоновым видео и авторизацией через Google OAuth 2.0.

## Стек

### Frontend

- Vanilla TypeScript
- CSS
- Vite
- WebSocket

### Backend

- Python
- FastAPI
- Google OAuth 2.0

## Статус

Проект находится в разработке.

## Запуск frontend

Требуется Node.js 20+.

```bash
npm install
npm run dev
```
